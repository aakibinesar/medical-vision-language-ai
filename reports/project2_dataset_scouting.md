## Top recommendation

**Start with STNet (He et al. 2020 / bryanhe/ST-Net, Mendeley Data 29ntw7sh4r) for Gate 0 and Gate 1.**

Reasoning: it is the only candidate that simultaneously verifies *all* the required properties with the least friction — 23 explicit patient IDs (enough for a genuine patient-level train/val/test split, directly addressing the "Critical" spot-level-leakage risk called out in the source plan), open Mendeley hosting with no password gate or DUA (unlike HER2ST's 7z-encrypted, contact-the-authors access), a manageable footprint relative to HEST-1k's multi-terabyte scale, and a companion open-source codebase (`bryanhe/ST-Net`) that already implements patient-aware splitting, giving a working reference for what "correct" alignment and splitting look like. It is also a widely cited benchmark, so unimodal (histology-only, expression-only) baseline numbers from other papers exist for sanity-checking Gate 1 results.

**Fallback:** HER2ST is the second choice — smaller (630MB, very laptop-friendly) and equally well patient-labeled, but its access requires emailing the authors for 7z passwords, which is a lead-time cost worth starting *in parallel* now (send the request this week) in case STNet's Mendeley size or format turns out to be awkward. A single 10x Genomics Visium breast-cancer sample (e.g., Block A Section 1, CC BY 4.0, no access friction at all) is a good **Gate 0 "does alignment even work" smoke test** before committing to either multi-patient dataset, precisely because it requires zero download friction and is a single, tiny, well-documented sample.
